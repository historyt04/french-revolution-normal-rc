## 실제 배포 화면 확인
- 유효 학생 인증을 보안 입력으로 완료.
- 학생 화면의 초급 10문항을 직접 제출. 마지막 제출 직후 기기 저장 안내, 이후 서버 완료 화면.
- DB: 완료 attempt 1건, beginner record 1건, basic 팩 3→4개.
- 보관함의 한 개 개봉과 Enter 공개 확인. DB: basic 팩 4→3개, 카드 1장, 개봉 이력 1건.
- 새로고침 후 초급 완료·10 XP·카드 1장·팩 3개 유지.
- 아직 로그아웃 후 재인증 및 5/15/30명 흐름은 미검증.
- 기존 버전에는 요청별 계측이 없어 로그인·완료·팩 요청 시간을 정확하게 측정하지 못함. 자동화 도구 호출 시간은 게임 속도로 보고하지 않음.
- 발견한 표시 오류: 10문항 완료 결과가 10/12로 표기. 후속 UI 수정 대상으로 보존.

## 운영 목적

## 다음 승인할 구체적 작업
별도 RC(history_v5)에서 기존 교사 학생 등록 기능으로 2026학년도 2학년 98반 1~30번, 이름 RC시험01~RC시험30을 생성한다. 기존 실학생 명부와 교사 권한/설정은 수정하지 않는다. 접속 코드는 표준 무작위 발급이며 외부 로그/소스에 저장하지 않는다.
같은 30명을 이용해 5명 → 15명 → 30명 순으로 전체 흐름과 재접속/중복 요청을 시험하고, 통과 시 25명 로그인 표본을 추가한다. 남은 운영 기록은 시험용이다.
