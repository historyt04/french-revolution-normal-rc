## 변경
- game-api.js: 최소 로그인 후 별도 출석 요청으로 기존 학생 상태 형식 연결.
- student-v42.js: RC별 상태 캐시 분리.
- student-v43-speed.js: 준비·활성화 요청 ID 고정, 짝맞추기 완료 저장 연결.
- student-fast-quiz.js: 초급·중급 마지막 답안 후 즉시 저장 대기 화면.
- normal-rc-outbox.js: 학생 ID와 서버별 IndexedDB 완료 답안, 재접속 시 같은 ID 재전송, 다른 학생 전송 거부, 서버 확인 후 확인 상태 저장.
- normal-rc-client.js: 저장 전/기기 보관/서버 확인 상태 연결, 저장 실패 경고, 미확인 완료가 있으면 새 게임 시작 제한.
- student-preview.html, teacher.html, teacher.js: 새 연결 파일과 별도 학생 검증 주소 연결.
- tests/normal-rc-outbox.test.cjs, tests/normal-rc-storage-browser.html: 장애/기기 저장소 검사.
- DB 변경 없음. 새 RC에서만 배포하며 원본 main과 기존 API는 유지.

## 검증된 범위
- Node 문법 검사 통과.
- 로컬 완료 큐 테스트 통과: 응답 유실, 새 큐 인스턴스 재시작, 학생 간 분리, ID 충돌, 로컬 저장 실패, 확인 저장 실패 재전송, 오류 답안 보존.
- 기존 도메인/트랜잭션 회귀 테스트 통과. 메모리 어댑터이며 배포 서버 부하 결과가 아님.
- v43 속도 회귀 테스트 통과. 기존 가짜 저장소이며 실제 학생 30명 결과가 아님.
- 실제 브라우저 IndexedDB 검증과 인증 학생 흐름은 배포 후 확인해야 한다.

## 미완료 / 위험
- 모든 게임 모드 완료 큐는 아님: 초급·중급·짝맞추기에 우선 연결. 순서/연결고리/지도 모드 추가 필요.
- 출석 응답은 아직 학생 전체 개인 상태를 포함한다. 카드/도감/미션의 화면별 조회 분리 필요.
- 카드팩 서버 원자성/멱등성은 구현했지만 클라이언트의 세션을 넘는 개봉 요청 복구는 추가 연결 필요.
- 실제 브라우저 5/15/30명 전체 흐름, 25명 로그인, 성능 목표 및 실학생 5~7명 시험 미실시.
- 저장 공간 부족/브라우저 데이터 삭제는 기록 보관을 보장할 수 없음. 실패 시 화면을 닫지 않도록 경고.
- 서버 검증 오류 답안은 기기에 남기며 보상을 임의 지급하지 않는다. 만료/잠금 변경 시 처리 정책을 추가 검토해야 한다.
- 아직 정상 서버 개편 성공 체크포인트가 아니므로 요청된 메뉴/고급/FR-09 UI 변경은 시작하지 않았다.
